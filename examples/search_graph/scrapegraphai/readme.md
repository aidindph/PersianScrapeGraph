# مثال Search Scraper با API سرویس ScrapeGraph

این پوشه نمونه‌هایی برای استفاده از سرویس ابری ScrapeGraph (از طریق SDK پایتون) در سناریوی «جست‌وجو و سپس استخراج» دارد:

- `searchscraper_scrapegraphai.py` — جست‌وجوی وب با زبان طبیعی و استخراج اطلاعات ساخت‌یافته از چند منبع
- `searchscraper_scrapegraphai_v3.py` — نسخهٔ v3 همان سناریو

> **نکته:** برای اجرا به `SCRAPEGRAPH_API_KEY` نیاز دارید؛ آن را در متغیرهای محیطی یا فایل `.env` قرار دهید. راهنمای کامل در [README پوشهٔ smart_scraper_graph/scrapegraphai](../../smart_scraper_graph/scrapegraphai/readme.md) آمده است.
