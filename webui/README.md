# 🖥️ داشبورد وب فارسی — PersianScrapeGraph WebUI

رابط کاربری کامل و **فارسی/راست‌چین** برای موتور استخراج دادهٔ ScrapeGraphAI، ساخته‌شده با **Next.js 16 + TypeScript + Tailwind CSS 4 + shadcn/ui**.

> [!NOTE]
> **توسعه‌دهنده فارسی و توسعه‌دهنده UI:** [آشیانه پارس](https://parsnest.com) — [طراحی سایت](https://parsnest.com) | [طراحی نرم‌افزار](https://parsnest.com)

## ✨ ویژگی‌ها

- 🇮🇷 **رابط صددرصد فارسی و راست‌چین (RTL)** با تایپوگرافی درست («»، نیم‌فاصله، اعداد فارسی)
- 🔤 **فونت ایران‌یکان** (Light / Regular / Bold — همراه پروژه، بدون نیاز به CDN خارجی)
- 📅 **تقویم جلالی** برای نمایش تاریخ امروز و تاریخچهٔ استخراج‌ها (`Intl.DateTimeFormat('fa-IR')`)
- 🕷️ **اسکرپر هوشمند دمو**: آدرس صفحه + دستور فارسی → خروجی JSON ساخت‌یافته با هوش مصنوعی
- 📜 **تاریخچهٔ استخراج‌ها** با ذخیره‌سازی در دیتابیس (Prisma + SQLite) — قابل مشاهده، بازیابی و حذف
- ⚙️ **اتصال موتور واقعی**: با تنظیم `SCRAPE_API_URL`، استخراج‌ها به گراف کامل ScrapeGraphAI در سرویس [`api-service/`](../api-service/) ارسال می‌شوند
- 📱 **کاملاً واکنش‌گرا** (موبایل → دسکتاپ) با حالت‌های بارگذاری، خطا و بازخورد Toast

## 🚀 اجرای محلی

پیش‌نیازها: **Bun** (پیشنهادی) یا Node.js 20+، و یک سرویس Ollama در صورت استفاده از مدل محلی.

```bash
cd webui

# ۱) نصب وابستگی‌ها
bun install

# ۲) ساخت دیتابیس SQLite برای تاریخچه
bun run db:push

# ۳) کپی متغیرهای محیطی و تنظیم آن‌ها
cp .env.example .env

# ۴) اجرای سرور توسعه
bun run dev
```

سپس <http://localhost:3000> را باز کنید.

## 🔑 متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `DATABASE_URL` | `file:../db/custom.db` | مسیر دیتابیس SQLite (نسبت به پوشهٔ `prisma/`) |
| `SCRAPE_API_URL` | خالی | نشانی سرویس [`api-service`](../api-service/)؛ اگر تنظیم شود موتور واقعی جای دمو را می‌گیرد |

## 🧩 معماری دو حالته

```
┌─────────────┐    SCRAPE_API_URL تنظیم نشده    ┌──────────────────┐
│             │ ─────────────────────────────► │  حالت دمو (سبک)   │
│   webui     │    دریافت صفحه + LLM دمو        │  بدون نصب پایتون   │
│  (Next.js)  │                                 └──────────────────┘
│             │    SCRAPE_API_URL تنظیم شده     ┌──────────────────┐
│             │ ─────────────────────────────► │  api-service      │
└─────────────┘    POST /scrape                │  (گراف کامل SGAI) │
                                                └──────────────────┘
```

- **حالت دمو** (پیش‌فرض): صفحهٔ هدف در همان route دریافت و پاکسازی می‌شود و با یک LLM سبک به JSON تبدیل می‌شود — مناسب نمایش و تست سریع. اگر اعتبارنامهٔ LLM دمو در محیط شما پیکربندی نشده باشد، پیام راهنمای فارسی دریافت می‌کنید.
- **حالت موتور واقعی**: کافی است `SCRAPE_API_URL` را به سرویس FastAPI راهنمای [`api-service/`](../api-service/) اشاره دهید تا **گراف کامل ScrapeGraphAI** (Playwright، RAG، هر مدل LLM) اجرا شود.

## ☁️ استقرار روی Vercel

راهنمای گام‌به‌گام فارسی: **[docs/deploy-vercel.md](../docs/deploy-vercel.md)**

خلاصه: در داشبورد Vercel ریپو را Import کنید و **Root Directory** را روی `webui` بگذارید — همین!

> ⚠️ توجه: SQLite در محیط serverless پایدار نیست؛ تاریخچه در استقرار ابری موقتی است و برنامه بدون دیتابیس هم کار می‌کند (خروجی استخراج برمی‌گردد، فقط تاریخچه ذخیره نمی‌شود). برای تاریخچهٔ پایدار از Postgres استفاده کنید.
